## Package Overview

`fast_rc` is an R package that provides fast reverse complement
operations for DNA/RNA sequences via Rcpp (C++ integration). The core
function
[`fast_rc()`](https://steverozen.github.io/reference/fast_rc.md) uses a
static lookup table for O(1) complement mapping with full IUPAC
ambiguity code support.

## Architecture

- **`src/rast_rc.cpp`** — The core C++ implementation. Exports
  `fast_rc(CharacterVector seqs, std::string type)` to R via Rcpp.
  Supports DNA (A↔︎T) and RNA (A↔︎U) modes with case-insensitive IUPAC
  complement mapping and NA preservation.
- **`R/fast_rc-package.R`** — Package-level roxygen2 directives; imports
  [`Rcpp::sourceCpp`](https://rdrr.io/pkg/Rcpp/man/sourceCpp.html).
- **`tests/testthat/`** — testthat edition 3 test files.
- NAMESPACE is auto-generated by roxygen2; do not edit manually.
